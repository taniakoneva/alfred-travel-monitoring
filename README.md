# Альфред: отслеживание рейсов и перепланирование поездки

> Альфред — персональный помощник путешественника, который следит за поездкой, пока путешественник занимается своими делами.

Учебный проект по системному анализу: проектирование подсистемы TravelTech-сервиса, которая следит за рейсами, предупреждает о задержках и отменах, предлагает замену и обновляет общий план поездки. Это документация и диаграммы, кода в репозитории нет.

## Задача

TravelTech-сервис планирует поездки: билеты, отели, трансферы, активности, всё в едином интерфейсе. Нужно спроектировать систему, которая:

- отслеживает статус рейсов пользователей (через внешние API или рассылки);
- при задержке или отмене уведомляет пользователя;
- автоматически предлагает альтернативные рейсы или активности;
- обновляет общий план путешествия.

Учесть: данные о рейсах приходят с задержкой, пользователь может быть оффлайн, альтернативы должны учитывать багаж, визы и таймзоны. Паспортные данные нельзя хранить дольше, чем необходимо для поездки.

## Решение в двух словах

- **Событийная архитектура.** Пять сервисов общаются через шину событий, поэтому сбой одного не теряет изменения.
- **Сначала сообщаем, потом ищем.** Первое уведомление уходит сразу, не дожидаясь подбора альтернатив.
- **Билеты меняются только после выбора пользователя** (в группе: организатора).
- **Варианты сначала фильтруются, потом ранжируются.** Вариант без нужной визы или с невозможной пересадкой не показывается вообще.
- **Защита от дублей и старых событий**, версии общего плана, жизненный цикл инцидента.
- **Паспорта:** отдельное шифрованное хранилище, токены, автоматическое удаление.
- **MVP** без автоматической переброни, с понятным планом на вторую версию.
